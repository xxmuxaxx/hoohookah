# hoohookah

Лендинг «Хухука» с конструктором кальяна: выбор модели и деталей, живое SVG-превью, промокод, доставка и оформление заказа (демо, заказ никуда не отправляется). Vite + SCSS + JS без фреймворков, все изображения — собственные SVG.

Нужен Node.js 20.19+.

```sh
npm install
npm start       # dev-сервер
npm run build   # сборка в public/
npm run lint    # eslint + stylelint с автоисправлением
```

Каталог деталей, цены, доставка и демо-промокоды — в `src/js/constructor/catalog.js`.
